# overtime 스킬

야근 일지 Canvas 표를 커맨드 인자만으로 채운다.

- **Canvas**: `F0BNWCDB163` — [야근 일지](https://clo3d.slack.com/docs/T04BT3VBR/F0BNWCDB163)
- Josh 영역만 기입. **`[리더] 승인` · `[리더] PnC 전달 여부`는 절대 기입 금지** (항상 빈칸 유지)

---

## 표 컬럼 (10개, 순서 고정)

```
Date | 연장 근무 사유 | [계획] 시작 시간 | [계획] 완료 시간 | [리더] 승인 | 시작 시간 | 완료 시간 | 저녁 식사 시간 | Overtime | [리더] PnC 전달 여부
```

---

## 모드

### 1. 계획 등록 (기본 — 야근 전에 실행)

```
/overtime 19:00-22:00 Checkout WF 작업
/overtime 19-22 Checkout WF 작업        ← 시만 쓰면 :00으로 해석
```

새 행 생성: `Date`(오늘) + `연장 근무 사유` + `[계획] 시작·완료 시간` 기입. 나머지 6칸 빈칸.

### 2. 실적 기입 (야근 후)

```
/overtime done 19:00-22:30 식사 1H
/overtime done 19-22:30                  ← 식사 생략 시 확인 질문
```

오늘 날짜 행(없으면 가장 최근의 실적 미기입 행)을 찾아 `시작 시간` · `완료 시간` · `저녁 식사 시간` · `Overtime`만 채운다.

- 대상 행이 없으면 에러: "계획 행이 없어요. `/overtime 19-22 사유` 로 먼저 등록해 주세요."
- 식사 인자가 없으면 사용자에게 확인 (기본값 임의 적용 금지)

## 파싱·검증 규칙

| 항목 | 규칙 |
|---|---|
| 시간 형식 | `HH:MM-HH:MM` 또는 `HH-HH` (`19-22` → `19:00-22:00`) |
| 분 단위 | **00 / 30만 허용.** 그 외(19:23 등)면 기입하지 않고 에러: "시간은 30분 단위로만 입력할 수 있어요 (예: 19:00, 19:30)" |
| 자정 넘김 | 완료 < 시작이면 익일로 간주 (22:00-01:00 → 3H) |
| 날짜 | 실행일 자동. `--date 8/12` 옵션으로 소급 기입 가능 |
| Date 셀 형식 | Canvas date chip: `![](slack_date:YYYY-MM-DD)` |
| 식사 표기 | `1H` / `30M` / `1H 30M` 형태 그대로 셀에 기입 |

### Overtime 계산

```
Overtime = 완료 − 시작 − 식사 시간 → 시간 단위 버림
예: 19:00~22:30, 식사 1H → 2H 30M → "2H"
예: 09:50 실적은 입력 불가 (30분 단위 검증에서 걸러짐)
```

결과 출력 시 계산 근거를 함께 보여준다: `Overtime 2H (22:30 − 19:00 − 식사 1H = 2H 30M → 버림)`

## 실행 흐름

```
Step 1 — 인자 파싱: 모드(plan/done) · 시간 · 사유 · 식사 · --date
         검증 실패 시 Canvas 접근 없이 즉시 에러 출력 후 중단
Step 2 — slack_read_canvas(F0BNWCDB163) → 표 섹션 ID + 현재 표 마크다운 확보
         (섹션 ID는 매번 새로 읽는다 — 이전 세션·이전 턴 ID 재사용 금지)
Step 3 — 표 재구성
         plan: 기존 행 전부 보존 + 새 행 추가 (내용 없는 빈 행이 있으면 그 행을 교체)
         done: 대상 행의 4개 셀만 채우고 나머지 셀·행은 원문 그대로 보존
Step 4 — slack_update_canvas: 표 섹션 replace (표 전체가 한 섹션이므로 전체 재구성)
Step 5 — 기입 결과 요약 + canvas_url 출력
```

## 주의사항

- 리더 컬럼 2개(`[리더] 승인`, `[리더] PnC 전달 여부`)는 어떤 모드에서도 기입 금지

- Canvas 쓰기 실패 시 재시도 전에 read부터 다시 (섹션 ID 갱신됨)
