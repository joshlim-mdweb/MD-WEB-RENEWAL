새 스킬 파일을 표준 포맷으로 생성한다.

## 실행 순서

1. `$ARGUMENTS`에서 스킬 이름과 목적 파싱
   - 예: `review-pr — PR 코드 리뷰 자동화`

2. `.claude/commands/<name>.md` 파일 생성:
   - 첫 줄: 스킬의 목적을 한 문장으로 설명
   - 실행 단계를 번호 순서로 작성
   - `$ARGUMENTS`를 입력값으로 받는 경우 마지막 줄에 명시
   - OPINION 프로젝트 컨텍스트에 맞게 작성

3. 생성된 파일 경로와 사용 방법을 출력한다:
   - 예: `/name [인수]` 형식으로 사용

스킬 정보: $ARGUMENTS
