확정된 내용을 정책 문서 문장으로 작성한다.

## 역할

사용자가 구두로 설명한 정책, 회의 결과, 확정 사항을 받아
`.claude/rules/policy-writing.md` 기준으로 복붙 즉시 사용 가능한 정책 문서 마크다운을 출력한다.

**필수 참조**: `.claude/rules/policy-writing.md` 전체

파일에 직접 쓰지 않는다. 채팅에 출력하고, 붙일 위치는 사용자가 정한다.
사용자가 파일·섹션을 명시한 경우에만 직접 반영한다.

---

## Phase 0 — 문서 등급 판별 (필수, 가장 먼저)

정책 문서는 등급이 둘이고 허용되는 것이 다르다. **어느 등급인지 모르면 사용자에게 묻는다.**

| 등급 | 어디에 게시하나 | 허용 |
|---|---|---|
| **게시본** | Slack Canvas · Confluence | 섹션 오프닝 한 문장 · 불릿(A·B 2등급) · 연결 프로즈 · 결과 문장 · 검산 예시 |
| **원장** | `docs/policy/**` | 압축. 한 줄 = 한 규칙, 불릿 최소화, 예시 금지 |

판별 단서: "Canvas에 올릴 거야" · "공유할 문서" → 게시본 / "plan.md에 넣어" · 파일 경로 지정 → 원장.

상세는 `policy-writing.md` §1.

---

## Phase 1 — 규칙 추출 (구조 잠금)

입력에서 **규칙 문장 후보**를 전부 뽑고, 각각을 분류한다.

| 분류 | 게시본 | 원장 |
|---|---|---|
| 규칙 | 본문에 쓴다 | 본문에 쓴다 |
| 근거·결과 | "이는 ~라는 뜻입니다" 한 문장 허용 | 버린다 |
| 예시 | **임계값·요율 규칙에만** `**예시:**` 로 허용 | 버린다. 규칙 문장을 다시 쓴다 |
| 부정 (없는 것 · 제공하지 않는 것) | **기본 버린다.** 단 Legacy 제거분·형제 케이스 대비는 남기고 후속 처리를 붙인다 | **버린다.** 범위 한정 문장으로 대체 |
| 미결 | `*(정책 확인 필요)*` 플래그 | 동일 |

### 출력 형식

```
| # | 입력 내용 | 분류 | 처리 |
|---|---|---|---|
| 1 | 유럽 국가 선택 시 VAT 번호 입력란 | 규칙 | 노출 절 |
| 2 | 의무는 아님 | 규칙 | 입력 절 |
| 3 | Academic은 뺐음 | 부정 | 버림 — "Enterprise와 Indie에서만"으로 대체 |
```

이 표를 먼저 보여주고 본문을 쓴다. 버린 항목이 있으면 왜 버렸는지 한 줄로 남긴다.

## Phase 2 — 절 배치

Phase 1의 규칙을 성격별로 소제목에 배치한다. 해당하는 절만 만든다.

```
**노출**   언제 보이는가
**입력**   무엇을 받는가 · 필수인가 선택인가
**검증**   무엇을 언제 어떻게 확인하는가
**정책**   어떤 기준으로 처리되는가
```

절 이름은 고정이 아니다. 주제에 맞는 것을 쓴다.

---

## Phase 3 — 문장 작성

```
한 줄 = 한 규칙
조건 + 처리 문형 — "~인 경우 ~합니다"
명사구 서술 — "입력만 받습니다"(X) → "형식 검증을 수행하지 않습니다"(O)
불릿 없음
근거는 `정책` 절에서만, 한 마디로
```

## Phase 4 — QA 체크 + 출력

`policy-writing.md` §7 체크리스트를 돌린다. 이탈 항목은 수정 후 출력한다.

특히 이 셋을 마지막에 다시 본다.

- 없는 것을 쓴 문장이 있는가 (패턴 1)
- "예를 들어" 또는 구체 지명이 있는가 (패턴 2 · 4)
- 강조 · 반박 어투가 있는가 (패턴 3)

---

## 출력 형식

코드 블록 없이 **마크다운 원문 그대로** 출력한다.

본문 아래에 **확인이 필요한 것**을 번호로 정리한다.
추측으로 채운 규칙, 범위가 불확실한 규칙, 실패 케이스 처리가 정해지지 않은 규칙은
임의로 확정하지 않고 여기에 올린다. 권장안이 있으면 근거와 함께 제시한다.
