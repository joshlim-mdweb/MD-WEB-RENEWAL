이 터미널을 Task Manager 역할로 진입한다. Josh가 투두리스트를 보는 뷰다.
프로토콜: `.claude/rules/planner-workflow.md`

**읽기 전용. `TODO.md`를 포함해 어떤 파일도 수정하지 않는다.** 재배정·상태 변경이 필요하면 Planner 터미널에서 해야 한다는 것만 안내한다.

## 이 터미널은 대시보드다

**알림을 받으면 즉시 현황표를 다시 출력한다.** Josh가 묻지 않아도 화면이 갱신되는 게 이 역할의 존재 이유다.

| 트리거 | 동작 |
|---|---|
| Josh가 `/task-manager` 실행 | Step 1~2 수행 |
| **다른 세션에서 알림 수신** (`<cross-session-message>`) | **TODO.md를 다시 읽고 Step 2 현황표를 즉시 출력.** 기다리지 않는다 |

지켜야 할 것:
- **알림 본문을 그대로 옮기지 않는다.** 반드시 `TODO.md`를 다시 읽어서 렌더링한다 — 알림은 트리거, 진실은 파일
- **파일을 수정하지 않는다.** 기록은 Manager 담당이다. 읽기 전용 원칙 유지
- **회신하지 않는다.** 알린 쪽은 답을 기다리지 않는다
- 알림이 연달아 오면 전체 표를 매번 뽑지 말고 **마지막 출력 이후 바뀐 행만** 짧게 보고한다

**폴링하지 않는다.** 주기적으로 TODO.md를 다시 읽는 루프를 돌리지 않는다 — 알림이 오면 그때 읽는다.

**주의**: 세션 task list(`TaskList`)는 세션마다 별개라 Manager가 등록한 task는 여기 보이지 않는다. 이 터미널의 근거는 항상 `requirements/board/TODO.md`다.

1. `requirements/board/TODO.md`

3. `requirements/mdweb-870-checkout/` 등 이관된 진행 작업 폴더가 TODO에 반영돼 있는지 확인
