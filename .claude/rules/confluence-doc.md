# Confluence 문서 작성 규칙

적용 범위: Confluence 페이지 작성 전체

---

## 문체

문서 타입별로 말투를 구분한다.

| 문서 타입 | 말투 | 예시 |
|-----------|------|------|
| 정책서 | `~합니다` | "14일 무료 Trial을 제공합니다." |
| 기능명세서 | `~할 수 있다` | "사용자는 플랜 카드에서 Start Now를 클릭할 수 있다." |
| 컨텐츠 | 명사형 | "14일 무료 체험" |

- **불릿 항목**: 명사형 또는 단문 종결 — 서술어 없이 딱 떨어지게
- **테이블 셀**: 명사형 단어 또는 값 단독 표기

```
✅ 정책서 본문: "이 문서는 Plan 페이지의 비즈니스 정책을 정의합니다."
✅ 기능명세서 본문: "사용자는 버튼을 클릭해 Checkout으로 진입할 수 있다."
✅ 불릿: "- 월간 자동결제"  /  "- 최대 2회 구매 제한"
❌ 불릿: "- 월간 자동결제를 지원합니다"
```

---

## 구조 규칙

- **H2**: 최상위 섹션 (개요 / 플랜 종류 / 정책 등)
- **H3**: 섹션 내 소분류
- **테이블 우선**: 비교·분기 조건은 테이블로 표현
- **불릿은 나열형**에만 사용 — 조건 분기는 테이블 사용

---

## 금지 표현

| 금지 | 대체 |
|------|------|
| `~입니다` (단독 서술) | `~합니다` |
| `~해요` / `~이에요` | `~합니다` |
| `~됩니다` (수동) | `~합니다` (능동 전환) |
| 불릿에 `~합니다` 종결 | 명사형으로 끝내기 |
