Core Value 1 주름을 그리는 대신, 물성을 반영해 움직이게 디스크립션  천의 성질과 움직임을 반영해, 손으로 그린 듯한 표현이 아니라 실제처럼 반응하는 의상을 만들 수 있어요. 형태를 만드는 데서 끝나지 않고, 옷이 움직임 안에서 어떻게 흘러가는지까지 더 자연스럽게 확인할 수 있습니다. 메모에도 “옷 주름을 한땀한땀 안 그리고 → 물리엔진”, “가상의 중력 → 시뮬레이션”이라는 방향이 명확하게 적혀 있습니다. 하단 Related Feature 카드 Simulation Modeling  폴리곤을 직접 깎기보다, 시뮬레이션 기반으로 의상의 형태를 더 빠르게 잡을 수 있어요. 메모에서도 대표 기능은 Animation보다 Simulation Modeling에 더 무게를 둬야 한다고 정리돼 있습니다. REST API  외부 파이프라인과 연결해 필요한 작업 흐름을 더 유연하게 구성할 수 있어요. 공식 문서의 API List에는 REST API가 포함되어 있습니다. 4. Layered Garments  여러 겹 의상과 복잡한 구조도 안정적으로 다루면서 실루엣과 디테일을 더 정교하게 만들 수 있어요. 이 카드는 실제 기능명보다 결과 중심 라벨로 두는 편이 더 읽기 쉽습니다. 메모에서도 “여러겹”, “복잡한 레이어 시뮬레이션”이 핵심 포인트로 반복됩니다. 5.
