## 1. 기본 원칙

- **신규 가입은 CLO-SET에서만 가능하다.** MD 사이트에는 Sign Up 버튼을 제공하지 않는다.
- **로그인은 CLO-SET 계정과 Legacy(MD 자체) 계정 모두 허용한다.**
  - CLO-SET 계정: "Continue with CLO-SET" 버튼 → CLO-SET 인증 후 MD 진입
  - Legacy 계정: 이메일 + 비밀번호 직접 입력 → MD 자체 인증
- CLO-SET 로그인을 Primary로 최우선 노출한다. Legacy 로그인은 "or" 구분선 아래 Secondary로 표시.
- 모든 CLO-SET MD 계정은 CLO-SET 계정과 1:1로 연결된다.
- 소셜 로그인(Google, Apple 등)은 CLO-SET에서 처리하며 MD는 관여하지 않는다.
- 로그인 완료 후 별도 온보딩 플로우 없이 MD에 바로 진입한다.

## 2. Sign Up 정책

**MD 자체 ID/PW 신규 가입을 전면 중단한다. 개인 사용자, 기업 계정 모두 해당한다.**
신규 가입은 CLO-SET 사이트에서만 가능하며, 가입 후 MD에 처음 로그인하면 Account가 자동 생성된다.

Sign In 화면의 "회원가입" 링크 클릭 시 CLO-SET 안내 화면으로 이동한다.

| 요소 | 내용 | 동작 |

## 3. Sign In 플로우

### 3-1. CLO-SET 계정 로그인 (Primary)

```
① Sign In 화면에서 "Continue with CLO-SET" 클릭
② CLO-SET 로그인 페이지로 리다이렉트 (return_url: MD)
③ CLO-SET에서 로그인 처리
④ CLO-SET 로그인 완료 → MD로 리다이렉트
⑤ MD: CLO-SET 토큰 검증 → 세션 생성
⑥ 원래 진입하려던 페이지 또는 MD 메인 진입
```

### 3-2. Legacy 계정 로그인 (Secondary)

```
① Sign In 화면에서 이메일/User ID + 비밀번호 입력
② "Sign In" 버튼 클릭
③ MD 자체 인증 처리
④ 성공 → 세션 생성 → MD 메인 진입
⑤ 실패 → 인라인 에러 (원인별 분기):
   - CLO-SET 통합 계정으로 레거시 로그인 시도:
     "이 계정은 CLO-SET을 통해 만들어졌거나 CLO-SET과 통합된 계정입니다."
   - 이메일/비밀번호 불일치:
     "라이선스 아이디/이메일 또는 비밀번호가 일치하지 않습니다."
```

### 3-3. 로그인 공통 규칙

- 이미 로그인된 상태에서 Sign In 진입 → 리다이렉트 없이 MD 메인으로 이동
- CLO-SET 서버 오류 → "일시적인 오류가 생겼어요. 잠시 후 다시 시도해 주세요."

## 4. Legacy 사용자 처리

| 상황 | 처리 |
| --- | --- |
| Legacy 계정으로 로그인 시도 | 허용 — MD 자체 인증으로 로그인 가능 |

| Legacy 계정 비밀번호 분실 | MD 비밀번호 찾기 플로우 (§5) 사용 |

## 5. 비밀번호 찾기 플로우 (Legacy 계정 전용)

CLO-SET 계정은 MD에서 비밀번호 찾기를 제공하지 않는다. CLO-SET 사이트에서 직접 처리.

```
① "비밀번호를 잊으셨나요?" 링크 클릭
② 이메일/User ID 입력 화면으로 이동
③ 이메일/User ID 입력 후 "재설정 링크 보내기" 클릭
   → 계정 타입 판별:
   [레거시 계정] → 재설정 링크 발송 → 이메일 발송 확인 화면
   [CLO-SET 계정] → 별도 화면 없음. 인라인 에러:
     "CLO-SET 계정으로 가입한 경우 통합 계정 로그인을 이용해 주세요."
   [미가입 이메일] → 동일 화면 유지. 인라인 에러:
     필드: "등록되지 않은 이메일이에요."
     버튼 클릭 후: "입력한 Email/User ID와 일치하는 계정을 찾을 수 없습니다."
   [형식 오류] → 인라인 에러: "이메일 형식을 다시 확인해 주세요."
   [미입력] → 인라인 에러: "Email/User ID를 입력해 주세요."
   [서버 오류] → 에러 토스트: "일시적인 오류가 생겼어요. 잠시 후 다시 시도해 주세요."
④ [레거시] 이메일의 링크 클릭 → 새 비밀번호 설정 화면
⑤ 새 비밀번호 입력 → 변경 완료 → Sign In 화면으로 이동
```

### 비밀번호 정책 (새 비밀번호 설정 화면)

| 조건 | 규칙 |
| --- | --- |
| 길이 | 최소 8자 이상, 최대 20자 이하 |
| 영문 | 소문자(a-z) 또는 대문자(A-Z) 포함 필수 |
| 특수문자 | `!-@#$%^&*()_+` 중 1개 이상 포함 필수 |
| 숫자 | 1개 이상 포함 필수 |

- 입력 시 실시간 검증: 충족 조건 초록색, 미충족 조건 빨간색 표시
- 비밀번호 불일치: "비밀번호가 일치하지 않아요."
- 정책 미충족 + 제출 시: "비밀번호는 8자 이상 입력해 주세요."
- 조건 미충족 또는 불일치 상태에서 "비밀번호 변경하기" 버튼 Disabled 유지

### 이메일 재발송

- 발송 후 60초 카운트다운. 0이 되면 "다시 보내기" 활성화.
- 재설정 링크 유효 시간: 24시간. 만료 시 만료 안내 화면.

### 이메일 마스킹

발송 확인 화면에서 이메일 주소를 마스킹 표시: `j***@example.com` (첫 글자 + *** + @ + 도메인).
