# POLICY_VERIFICATION

Source: 작업 세션 정의 (2026-06-16)

---

## 1. 적용 범위

이메일 인증 코드(OTP) 방식이 사용되는 인증 플로우 전체에 적용.

| 인증 유형 | 진입 경로 | 비고 |
| --- | --- | --- |
| Student 인증 | Plan → 학생 인증 → 서류 제출 → 이메일 코드 확인 | 재학 이메일 소유 확인. 코드는 입력한 학교 이메일로 발송 (2026-09-03 확정) |
| Academic 인증 | Plan → Academic 인증 → 서류 제출 → 이메일 코드 확인 | 가입 이메일로 발송 |
| Indie 인증 | Plan → Indie 인증 → 서류 제출 → 이메일 코드 확인 | 가입 이메일로 발송 |

---

## 2. 코드 유효시간

- 발송 후 **10분**간 유효
- 10분 초과 입력 시 에러: `"인증번호가 만료됐어요. 다시 보내기를 눌러 새 코드를 받아 주세요."`

---

## 3. 다시 보내기 (재발송)

| 항목 | 정책 |
| --- | --- |
| 쿨다운 | 재발송 후 **60초**간 비활성화 |
| 최대 재발송 횟수 | **5회** |
| 5회 초과 시 | 버튼 비활성화 + `"인증 이메일 발송 한도에 도달했어요."` + Contact Us 버튼 노출 |
| 재발송 시 이전 코드 | 즉시 무효화 |
| 재발송 성공 피드백 | `"인증 이메일을 다시 보내드렸어요."` 토스트 + 입력 박스 초기화 |

---

## 4. 인증번호 오류

| 오류 횟수 | 처리 | 에러 메시지 |
| --- | --- | --- |
| 1~4회 | 재입력 허용 | `"인증번호가 틀립니다."` |
| 5회 | 해당 코드 즉시 만료 + 입력 박스 잠금 + 인증하기 버튼 비활성화 | `"인증번호를 5회 틀려 코드가 만료됐어요. 다시 보내기를 눌러 새 코드를 받아 주세요."` |
| 재발송 시 | 새 코드 발급 + 오류 횟수 리셋 + 입력 박스 잠금 해제 | — |

---

## 5. 에러 메시지 전체

| 상황 | 메시지 |
| --- | --- |
| 코드 불일치 (1~4회) | `"인증번호가 틀립니다."` |
| 코드 만료 | `"인증번호가 만료됐어요. 다시 보내기를 눌러 새 코드를 받아 주세요."` |
| 오류 5회 초과 | `"인증번호를 5회 틀려 코드가 만료됐어요. 다시 보내기를 눌러 새 코드를 받아 주세요."` |
| 발송 한도 초과 | `"인증 이메일 발송 한도에 도달했어요."` + Contact Us 버튼 |
| 네트워크 오류 | `"일시적인 오류가 생겼어요. 잠시 후 다시 시도해 주세요."` |

## 6. 미결 정책 *(확인 필요)*

- Academic / Indie 발송 이메일: 가입 이메일 가정 — 확인 필요
- 재발송 5회 초과 후 자동 해제 여부 (현재: 영구 차단, Contact Us 유도)
