## 웹파트 관여 가능 영역

### 1. 베타 설치파일 배포 (확인 필요)
- 다운로드 페이지에서 EA 참가자에게만 베타 버전 노출 가능한지
- 로그인 상태 + EA 참가자 플래그 기반 분기 처리 필요할 수 있음
- **확인 필요**: 배포를 CVF 다운로드 페이지에서 할지 vs. CloverFamily에서 할지

### 2. EA 신청 페이지 (Public Wave)
- 공개 지원 받는 페이지
- MD 계정 이메일 + 구독 상태 검증
- 웨이트리스트 처리

### 3. 피드백 수집 폼
- 버그 리포트 폼을 웹에서 만들지 vs. 외부 도구(Typeform/Jira Form) 사용할지
- 웹에서 한다면 로그인 유저 정보 자동 입력 + 제출 데이터 연동 필요
- **확인 필요**: 외부 도구 쓰면 웹파트 관여 없음
