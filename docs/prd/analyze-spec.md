# Survey Analyze 기능 최종 명세

<!-- version: 1.0.0 | 최초 작성: 2026-04-09 | 최종 수정: 2026-04-09 -->

---

## 0. Premise

- 그래프/분포도는 `GET /api/surveys/[id]/report` 재사용. 응답 표·비교 분석만 신규 API.
- 기존 `/survey/[id]/report` 페이지에 탭 추가. 별도 URL 없음.

---

## 1. 탭 구조

| 탭        | 활성 조건                     | 비활성 툴팁                         |
| --------- | ----------------------------- | ----------------------------------- |
| 응답 표   | 응답 1개+                     | "응답이 없어요"                     |
| 그래프    | 응답 5개+                     | "응답이 5개 이상이면 볼 수 있어요"  |
| 분포도    | 응답 5개+                     | "응답이 5개 이상이면 볼 수 있어요"  |
| 비교 분석 | 응답 10개+ & 선택형 질문 2개+ | "응답이 10개 이상이면 볼 수 있어요" |

**기본 탭:** 응답 1-4개 → 응답 표. 응답 5개+ → 그래프.

비활성 탭은 숨기지 않음 — 존재 보이되 클릭 차단 + cursor-not-allowed.

---

## 2. 응답 표 스펙

- 행 = 응답 1건, 열 = 질문 (order_index 순)
- 고정 컬럼: 응답 번호(`#N`, 최신순 역번호), 제출 시각(M월 D일 HH:mm)
- 정렬: created_at DESC 고정. 컬럼 정렬 미지원.
- 페이지네이션: 20행/페이지, URL `?page=1`

**셀 표시 규칙:**

| 타입      | 표시                              |
| --------- | --------------------------------- |
| 단일 선택 | 텍스트 그대로                     |
| 다중 선택 | "A, B, C"                         |
| 척도/별점 | 숫자 (예: "4")                    |
| 순위      | "1위 > 2위 > 3위"                 |
| 단답/서술 | 2줄 truncate + "전체 보기" → 모달 |
| 미응답    | "—"                               |

**상태:**

| 상태    | 문구                                                      |
| ------- | --------------------------------------------------------- |
| 로딩    | 스켈레톤 (헤더 + 3행)                                     |
| 빈 상태 | "아직 응답이 없어요. 설문을 공유해 보세요."               |
| 에러    | "데이터를 불러오지 못했어요. 잠시 후 다시 시도해 주세요." |

---

## 3. 그래프 스펙

**질문 타입별 차트:**

| 타입                       | 차트                                   |
| -------------------------- | -------------------------------------- |
| multiple_choice / dropdown | 수평 바                                |
| checkbox                   | 수평 바 (합계 > 100% 주석 필수)        |
| scale / grade              | 분포 바 (값별 count)                   |
| ranking                    | 수평 바 (평균 순위, 역순)              |
| short_text / long_text     | 텍스트 목록 (최대 5개 + "N개 더 보기") |

**카드 공통 필수 요소:**

- 질문 제목
- 모수: "전체 N명 중 M명이 응답했어요"
- 응답 수 + 비율(소수점 1자리)
- 최다 응답 항목: ACCENT 색상 강조

---

## 4. 분포도 스펙

**질문별 요약 카드:** 응답 N개 / 미응답 M개 + 1~3위 바 + Key Sentence

**Key Sentence 규칙 (규칙 기반 MVP):**

선택형:

- 1위 ≥ 50% → `"응답자의 N%가 '[선택지]'를 선택했어요"`
- 1위 < 50% → `"가장 많은 응답자 N명이 '[선택지]'를 선택했어요"`

척도형 (평균/최대값 비율):

- ≥ 70% → `"평균 N점으로 긍정적인 반응이에요"`
- 40~70% → `"평균 N점으로 중립적인 반응이에요"`
- < 40% → `"평균 N점으로 개선이 필요한 영역이에요"`

순위형: `"{항목}이 가장 높은 순위를 받았어요 (평균 N위)"`

텍스트형: `"응답 N개가 수집됐어요. 직접 답변을 확인해 보세요."`

---

## 5. 비교 분석 스펙

상세 스펙: `docs/prd/analyze-feature.md` (source of truth)

**쿼리 빌더 흐름:**

```
[기준 질문 ▼] 에서 [답변 ▼] 라고 한 응답자 중
[결과 질문 ▼] 에서 각 답변을 고른 사람: N명 (전체 M명 중 X%)
```

드롭다운 활성화 체인: 기준 질문 → 답변 → 결과 질문 선택 시 API 자동 호출 (조회 버튼 없음).

선택형 질문 1개 이하인 경우 탭 진입 허용 + 빈 상태: `"비교 분석을 하려면 선택형 질문이 2개 이상 필요해요"`

---

## 6. API 설계

| 탭              | API                                                                             | 결정              |
| --------------- | ------------------------------------------------------------------------------- | ----------------- |
| 그래프 / 분포도 | `GET /api/surveys/[id]/report`                                                  | 재사용            |
| 응답 표         | `GET /api/surveys/[id]/responses/table?page=1&limit=20`                         | 신규 ✅ 구현 완료 |
| 비교 분석       | `GET /api/surveys/[id]/analyze?question_id=&filter_question_id=&filter_answer=` | 신규 ✅ 구현 완료 |

---

## 7. 경계값 정책

| 응답 수             | 응답 표 | 그래프 | 분포도 | 비교 분석    |
| ------------------- | ------- | ------ | ------ | ------------ |
| 0개                 | ❌      | ❌     | ❌     | ❌           |
| 1-4개               | ✅      | ❌     | ❌     | ❌           |
| 5-9개               | ✅      | ✅     | ✅     | ❌           |
| 10개+ / 선택형 1개↓ | ✅      | ✅     | ✅     | ✅ (빈 상태) |
| 10개+ / 선택형 2개+ | ✅      | ✅     | ✅     | ✅           |

소규모(5명 미만) 경고 뱃지: `"응답이 적어 참고용으로만 활용해요"`

## 8. 구현 순서

| 단계 | 담당       | 작업                                      |
| ---- | ---------- | ----------------------------------------- |
| 1    | ✅ BE 완료 | `/responses/table` + `/analyze` API       |
| 2    | FE         | 4탭 컨테이너 + 활성/비활성 로직           |
| 3    | FE         | 응답 표 탭 (테이블 + 페이지네이션 + 모달) |
| 4    | FE         | 그래프 탭 (기존 report API 재사용)        |
| 5    | FE         | 분포도 탭 (요약 카드 + Key Sentence)      |
| 6    | FE         | 비교 분석 탭 (쿼리 빌더 + 결과)           |
| 7    | QA         | 전체 검증                                 |
