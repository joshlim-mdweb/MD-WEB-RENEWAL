## 1. 타겟 유저

### Primary
- 프리랜서 패션 디자이너 / 의류 디자이너 — 혼자 작업하며 클라이언트에게 납품
- 3D 아티스트 (게임, 영화, 광고) — 의류 시뮬레이션이 필요한 개인 작업자
- 크리에이터 / 인플루언서 — 디지털 패션 콘텐츠 제작 (메타버스, NFT 등)

### Secondary
- 학생 (Fashion Design, Game Art, Film VFX 전공) — 학업·포트폴리오 목적
- 사이드 프로젝트 작업자 — 본업 외 개인 작업물 제작

### 페인포인트
- 고가의 기업용 라이선스가 부담 — 혼자 쓰기엔 비싸다
- 월 단위로 유연하게 쓰고 싶다 (프로젝트 단위 계약)
- 학생은 커리큘럼에서 배운 툴을 졸업 후에도 이어 쓰고 싶다

## 2. 핵심 메시지

> "전문가 수준의 의류 시뮬레이션을, 나 혼자서도."

개인 사용자에게 MD를 선택해야 하는 이유: 접근성 (가격), 유연성 (월/연 선택), 전문성 (업계 표준 툴)을 동시에 전달한다.

학생 세그먼트에는 별도 가치 제안: "학교에서 배운 그 툴, 졸업 후에도 이어 쓰세요 — $99/년."

## 5. 운영 포인트

- Student 인증 상태(pending/완료/재인증 필요)에 따라 버튼 상태 실시간 반영 필요
- "For Student" 버튼 클릭 시 Student 페이지로 안내하는 툴팁 또는 링크 제공 검토
- Trial은 Personal 전용 (개인 계정만 해당). Enterprise / Academic / Indie는 Trial 없음 — 문의 통해 별도 협의.
- Trial 사용 이력 있는 Personal 유저가 재접근 시 Trial CTA 노출 금지 (이미 Subscription 전환 완료 상태)
- Trial 종료 후 자동 Subscription 전환 시점 명확히 고지 — 카드 정보 입력 시점(Trial 시작 전)에 안내 필수
