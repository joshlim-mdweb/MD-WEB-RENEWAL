## 3. 상태 정의

### "분석하기" 버튼

| 상태   | 조건                   | UI                                |
| ------ | ---------------------- | --------------------------------- |
| 숨김   | hover 없음             | opacity: 0                        |
| 표시   | 카드 hover             | opacity: 1, 150ms                 |
| 포커스 | 키보드 Tab             | opacity: 1, focus ring            |
| 활성   | 해당 카드 패널 열림 중 | ACCENT_SUBTLE 배경, ACCENT 텍스트 |
| 비활성 | endpoint / text 타입   | opacity: 0.4, cursor: not-allowed |
| 미렌더 | totalResponses === 0   | 렌더 안 함                        |

### AnalysisPanel

| 상태                | UI                                         |
| ------------------- | ------------------------------------------ |
| 닫힘                | translateY(100%), 250ms ease-in            |
| 열림 — 로딩         | 슬라이드업 300ms + 바 스켈레톤 3개         |
| 열림 — 기본 분포    | 바 차트, "전체 분포" 탭 활성               |
| 열림 — 교차 분석 탭 | 조건 빌더 UI                               |
| 열림 — 조건 로딩    | 이전 차트 유지 + 하단 스피너               |
| 열림 — 조건 결과    | 필터 뱃지 + 결과 차트                      |
| 빈 결과             | total_filtered === 0 → 빈 상태             |
| 소규모 경고         | insufficient_data → 차트 + amber 경고 뱃지 |
| 에러                | "다시 시도하기" 버튼                       |
| 질문 교체           | 슬라이드 없이 내용만 교체, 탭 초기화       |

## 4. 인터랙션 명세

### 패널 애니메이션

- 열릴 때: `translateY(100%) → 0`, 300ms, `cubic-bezier(0.32, 0.72, 0, 1)`
- 닫힐 때: `translateY(0) → 100%`, 250ms, ease-in
- 높이: 55vh → 조건 추가 시 70vh (200ms transition) → 최대 85vh

### 다른 질문으로 전환

- 슬라이드 없이 헤더 제목 fade(150ms) → 스켈레톤 → 데이터
- 교차 분석 탭 활성 시 → 기본 분포 탭으로 초기화 + 조건 초기화

### 조건 빌더 흐름

1. 조건 질문 선택 → 답변 드롭다운 활성화 (API 없음, options 사용)
2. 답변 선택 → 즉시 API 호출, 두 드롭다운 disabled (중복 방지)
3. 결과 표시 → 필터 뱃지 + 응답자 수 + 바 차트
4. "조건 없애기" → 초기화, 결과 fade-out

## 5. UX Writing

### 버튼 텍스트

| 위치              | 텍스트                       | Variant / Size |
| ----------------- | ---------------------------- | -------------- |
| 질문 카드 hover   | 분석하기                     | ghost / sm     |
| 패널 닫기         | aria-label: "분석 패널 닫기" | —              |
| 탭 1              | 전체 분포                    | —              |
| 탭 2              | 교차 분석                    | —              |
| 조건 초기화       | 조건 없애기                  | ghost / sm     |
| Key Sentence 복사 | 복사하기                     | ghost / sm     |
| Key Sentence 편집 | 편집하기                     | ghost / sm     |
| Key Sentence 저장 | 저장하기                     | primary / md   |
| 편집 취소         | 닫기                         | neutral / md   |
| 에러 재시도       | 다시 시도하기                | primary / sm   |

### 상태 문구

```
패널 기본 분포: "전체 응답 분포  ·  N명 응답"
조건 미선택: "조건 질문을 선택하면 특정 그룹의 응답만 볼 수 있어요"
자동 조회 힌트: "답변을 선택하면 바로 결과를 보여줘요"
필터 응답자 수: "전체 N명 중 M명 (X%)이 이 조건에 해당해요"
빈 결과: "이 조건에 해당하는 응답이 없어요. 다른 조건으로 다시 시도해 보세요"
소규모 경고: "응답이 적어 참고용으로만 활용해요"
비활성 tooltip: "이 질문은 분석할 수 없어요"
에러: "일시적인 오류가 생겼어요. 잠시 후 다시 시도해 주세요"
Key Sentence 저장 토스트: "핵심 문장을 저장했어요"
복사 토스트: "복사했어요"
인사이트 뱃지 양수: "전체 대비 +N%p 높아요"
인사이트 뱃지 음수: "전체 대비 -N%p 낮아요"
```

드롭다운 placeholder:

```
조건 질문 (초기): "질문을 선택해 주세요"
답변 (비활성): "먼저 조건 질문을 선택해 주세요"
답변 (활성): "답변을 선택해 주세요"
```

## 6. 접근성

- `body scroll-lock 절대 금지` — 패널 뒤 리포트 스크롤 유지
- 패널 내 포커스 트랩 (Tab이 패널 외부로 나가지 않음)
- ESC → 패널 닫기, 포커스 → 분석 시작 버튼으로 복귀
- 색상 단독 의미 전달 금지 — 바 차트 수치 레이블 병기 필수
- `role="dialog" aria-modal="true"` on 패널
- 로딩: `role="status" aria-live="polite"`
- 소규모 경고: `role="alert" aria-live="polite"`

- [ ] totalResponses === 0 → 버튼 미렌더
- [ ] 활성 카드 → ACCENT_SUBTLE 배경 표시

### AnalysisPanel

- [ ] body scroll-lock 절대 금지
- [ ] ESC 이벤트 cleanup
- [ ] 패널 닫힌 후 포커스 복귀
- [ ] 질문 교체 시 탭 + 조건 초기화
- [ ] 패널 높이 55vh → 70vh transition

### 조건 빌더

- [ ] 현재 분석 대상 질문 드롭다운에서 제외
- [ ] 비지원 타입 disabled
- [ ] 두 드롭다운 선택 완료 즉시 API 호출
- [ ] 호출 중 두 드롭다운 disabled

### 결과 표시

- [ ] insufficient_data → 차트 표시 + 경고 뱃지 (숨기지 않음)
- [ ] total_filtered === 0 → 빈 상태
