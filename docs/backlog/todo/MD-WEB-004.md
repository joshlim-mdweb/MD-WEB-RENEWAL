## 목적

기업 트라이얼 신청자가 200자 자유 입력 대신 구조화된 드롭다운으로 필요 정보를 빠르게 제출할 수 있도록 하여, 세일즈팀의 수동 처리 비용을 줄이고 리드 데이터 품질을 높인다.

BD 팀 미팅(2026-05-13) 결정: 개선안 A(드롭다운) + C(중국 조건부 필드) 진행. 개선안 B(이메일 도메인 차단)는 보류.

## 현황

- 기존 "요청 사항" 필드: 최소 200자 필수 입력 → 허수("asdfasdf") 유입, 고품질 리드 이탈 동시 발생
- 응답률 약 10~15% 미만, 1.5~2년 치 누적 데이터 중 허수 다수
- 담당자가 이메일로 수동 처리 — 실수·누락 발생
- 중국 지역: 이메일보다 WeChat/Mobile 소통이 빈번하나 현재 수집 필드 없음
- 이메일 도메인 차단(개선안 B)은 소규모 기업 gmail 사용, 회원가입 로직 불일치 문제로 이번 작업에서 제외

## 완료 조건 (Definition of Done)

- [ ] 요청 사항 200자 텍스트에어리어 → 구조화 드롭다운/체크박스로 교체
- [ ] 트라이얼 신청 목적 (다중 선택 체크박스, 필수)
- [ ] 예상 도입 시기 (드롭다운, 필수)
- [ ] MD 사용 경험 (드롭다운, 필수)
- [ ] 기타 요청 사항 (텍스트에어리어, 선택, 글자 수 제한 없음)
- [ ] 국가 = China 선택 시 WeChat ID + Mobile Number 필드 조건부 노출
- [ ] 중국 조건부 필드: 이메일은 의무 유지, WeChat/Mobile은 둘 중 하나 이상 필수
- [ ] 페이지 상단 안내 문구 추가 ("기업 및 교육 기관 대상 서비스"임 명시)
- [ ] 이메일 템플릿 — 드롭다운 선택값을 string으로 전송하도록 수정
- [ ] 어퍼스트로피 등 특수문자 데이터 처리 오류 수정
- [ ] QA 시나리오 통과

## 필드 정의 (개선안 A)

### 트라이얼 신청 목적 (필수, 다중 선택)
| 값 | 레이블 |
|----|--------|
| `garment_modeling` | 의상 모델링 기능 테스트 |
| `animation` | 애니메이션 기능 테스트 |
| `simulation` | 시뮬레이션 기능 테스트 |
| `pipeline` | 파이프라인 호환성 테스트 (Maya, Unreal 등) |
| `other` | 기타 (Other) |

### 예상 도입 시기 (필수)
| 값 | 레이블 |
|----|--------|
| `within_1m` | 1개월 이내 (Within 1 month) |
| `1_3m` | 1~3개월 이내 (1–3 months) |
| `3_6m` | 3~6개월 이내 (3–6 months) |
| `browsing` | 단순 기능 검토 (Just browsing) |

> **미결 사항**: "단순 기능 검토" 선택자에게 트라이얼 승인 여부, 별도 플로우 필요한지 BD팀 확인 필요.

### MD 사용 경험 (필수)
| 값 | 레이블 |
|----|--------|
| `first_time` | 처음 사용 / 신규 검토 |
| `personal_student` | 개인/학생 버전 사용 경험 있음 |
| `enterprise_legacy` | 기업용 구버전 사용 경험 있음 |

### 기타 요청 사항 (선택)
- 자유 텍스트, 글자 수 제한 없음

## 중국 조건부 필드 정의 (개선안 C)

| 필드 | 필수 여부 | 비고 |
|------|----------|------|
| WeChat ID | 선택 (둘 중 하나 이상) | |
| Mobile Number | 선택 (둘 중 하나 이상) | |

## UX 결정 사항

| 항목 | 결정 | 근거 |
|------|------|------|
| 이메일 도메인 차단 | 보류 | gmail 사용 기업 false positive + 회원가입 로직 불일치 |
| 기타 요청사항 | 선택으로 유지 | 고품질 리드는 자발적으로 입력 |

| 안내 배너 | 상단 추가 | 프리랜서/개인 유저 자연스러운 이탈 유도 |

## 이메일 템플릿 수정

- 드롭다운 선택값 → string으로 변환하여 전송 (예: `pipeline` → `"파이프라인 호환성 테스트 (Maya, Unreal 등)"`)
- 어퍼스트로피 등 특수문자 이스케이프 처리
- 트라이얼 발급 절차 안내 포함 (신청 → 매니저 검토 → 계정 생성 → 이메일 안내)

## 미결 사항 (BD팀 확인 필요)

1. 드롭다운 항목이 실제 기존 입력 패턴 기반인지 확인 → **고품질 요청 사례 공유 요청**
2. "단순 기능 검토" 선택자 승인 정책
3. 드롭다운 데이터 CRM 연동 여부 (현재 이메일 인박스로만 수신 중인지)
4. WeChat 대응 가능 세일즈 인력 현황

## CS 문의 예상 지점

| 예상 문의 | 대응 방법 |
|----------|----------|
| "신청했는데 연락이 없어요" | 안내 문구에 처리 기간 명시 (영업일 기준 N일) |
| "개인인데 신청할 수 있나요?" | 상단 배너로 사전 안내 → 개인 플랜 페이지 링크 |
| "중국인데 이메일이 없어요" | 이메일 필수 유지이므로 대안 없음 — BD팀과 정책 재확인 필요 |
