## 2. Background

사용자가 비로그인 상태로 앱을 다운로드하면 설치 후 로그인 화면에서 계정이 없어 진입이 불가하다. 이 문제로 "앱이 실행되지 않는다"는 CS 문의가 반복적으로 발생한다. 다운로드 페이지를 단순 파일 전달 지점에서 계정 생성·Trial 온보딩 진입점으로 전환해 이탈률을 낮추고 Trial 전환율을 높인다.

---

## 3. Requirements

| 기능명 | Description |
|---|---|
| 상태 배너 | 시스템은 로그인 상태에 따라 4가지 배너를 표시한다: 비로그인 / Trial 중 / 구독 중 / 만료 |
| 다운로드 버튼 — 게이트 없음 | 사용자는 로그인 없이 즉시 다운로드를 시작한다 |
| 버전·릴리즈 정보 | 시스템은 최신 버전 번호, 릴리즈 날짜, What's New 링크를 표시한다 |
| OS별 다운로드 버튼 | 시스템은 Windows(.exe)와 macOS 다운로드 버튼을 각각 제공한다. macOS는 Apple Silicon을 기본 버튼으로 표시하고, Intel 버전은 버튼 하단 서브 링크로 분기 제공한다 |
| 이전 버전 드롭다운 | 사용자는 "이전 버전 ▾" 드롭다운을 통해 구버전 파일을 다운로드한다 (기본 접힘) |
| 시스템 요구사항 탭 | 사용자는 Windows / macOS 탭을 클릭해 각 OS 요구사항을 확인한다 |
| GPU 경고 Callout | 시스템은 Intel/AMD GPU 미지원 사실을 요구사항 섹션 내 경고 Callout으로 표시한다 |
| 다운로드 후 Step Guide | 사용자가 다운로드 버튼을 클릭하면 3-Step Guide가 활성화된다 |
| Step 1 — 계정 만들기 | 비로그인 사용자에게 이메일 입력 + "14일 무료 체험 시작" CTA를 표시한다 |
| Step 2 — 설치하기 | 사용자는 Windows/Mac 설치 가이드 링크를 통해 설치를 진행한다. 설치 완료 후 "설치 완료" 버튼을 클릭하면 Step 3가 활성화된다 |
| Step 3 — 앱 실행 후 로그인 | 시스템은 계정 등록 완료 후 로그인 방법을 안내한다 |

## 4. Scope

### 4.1 Web (marvelousdesigner.com/product/download)

- 상태 배너: 로그인 상태 감지 후 4가지 배너 중 하나 표시
- 다운로드 메인 블록: 버전 정보 + OS별 다운로드 버튼 + 이전 버전 드롭다운
- 시스템 요구사항: Windows/macOS 탭 전환, GPU Callout
- Step Guide: 다운로드 클릭 시 활성화, 로그인 유저는 Step 1 자동 완료 처리

### 4.2 이메일 커뮤니케이션

- Step 1 완료(계정 생성) 시 Trial 환영 이메일 발송 (기존 이메일 플로우 연동)

## 5. Flow

### 5.1 비로그인 사용자 — 다운로드 + 계정 생성

| Step | Actor | Description |
|------|--------|--------------------------------------|
| 1 | 사용자 | 다운로드 페이지에 진입한다 |
| 2 | System | 비로그인 상태 배너("14일 무료 체험으로 시작하세요")를 표시한다 |
| 3 | 사용자 | Windows 또는 macOS 다운로드 버튼을 클릭한다 |
| 4 | System | 파일 다운로드를 즉시 시작한다 |
| 5 | System | Step Guide 섹션을 활성화하고 Step 1을 강조 상태로 표시한다 |
| 6 | 사용자 | 이메일 주소를 입력하고 "14일 무료 체험 시작" 버튼을 클릭한다 |
| 7 | System | 계정을 생성하고 Trial을 시작한다. 환영 이메일을 발송한다 |
| 8 | System | Step 1을 완료 처리하고 Step 2를 활성화한다 |
| 9 | 사용자 | 다운로드된 파일을 실행해 설치를 진행한다 |
| 10 | 사용자 | "설치 완료" 버튼을 클릭한다 |
| 11 | System | Step 2를 완료 처리하고 Step 3을 활성화한다 |
| 12 | 사용자 | 앱을 실행하고 등록한 이메일로 로그인한다 |

### 5.2 비로그인 사용자 — 이미 계정 있음

| Step | Actor | Description |
|------|--------|--------------------------------------|
| 1 | 사용자 | 다운로드 페이지에 진입한다 |
| 2 | System | 비로그인 상태 배너를 표시한다 |
| 3 | 사용자 | 다운로드 버튼을 클릭한다 |
| 4 | System | 파일 다운로드를 즉시 시작한다 |
| 5 | System | Step Guide를 활성화하고 Step 1을 강조 상태로 표시한다 |
| 6 | 사용자 | "이미 계정이 있어요 →" 링크를 클릭한다 |
| 7 | System | 로그인 페이지로 이동한다 |
| 8 | 사용자 | 로그인 완료 후 다운로드 페이지로 복귀한다 |
| 9 | System | Step Guide Step 1을 ✓ 완료 상태로 전환하고 Step 2를 활성화한다 |

### 5.3 로그인 사용자 — 다운로드

| Step | Actor | Description |
|------|--------|--------------------------------------|
| 1 | 사용자 | 다운로드 페이지에 진입한다 |
| 2 | System | 로그인 상태에 맞는 배너(Trial 중 / 구독 중 / 만료)를 표시한다 |
| 3 | 사용자 | 다운로드 버튼을 클릭한다 |
| 4 | System | 파일 다운로드를 즉시 시작한다 |
| 5 | System | Step Guide를 활성화하되, Step 1을 ✓ 완료 상태로 표시한다 |
| 6 | 사용자 | 다운로드된 파일을 실행해 설치 및 로그인을 진행한다 |

### 5.4 만료 사용자

| Step | Actor | Description |
|------|--------|--------------------------------------|
| 1 | 사용자 | 다운로드 페이지에 진입한다 |
| 2 | System | 만료 배너("구독이 만료됐어요. 갱신하면 최신 버전을 사용할 수 있어요." + 갱신 CTA)를 표시한다 |
| 3 | 사용자 | 다운로드 버튼을 클릭한다 (파일 다운로드는 허용) |
| 4 | System | 파일 다운로드를 즉시 시작한다 |
| 5 | System | Step Guide를 활성화하고 Step 1에 ⚠️ "플랜을 갱신하면 앱을 사용할 수 있어요." + 갱신 CTA를 표시한다 |
| 6 | 사용자 | 갱신 CTA를 클릭해 플랜 갱신을 진행하거나, Step 2(설치)로 넘어간다 |
