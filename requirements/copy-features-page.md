## Copy Rules (non-negotiable)

- Noun-based or verb-dropped endings
- No `~한다 / ~합니다 / ~됩니다`
- No abstract emotional phrasing ("powerful", "innovative", "seamless")
- Technical spec + result language, mixed — spec builds credibility, result builds desire
- Image is 70% of communication — copy supports, never leads
- "without" pattern preferred over explicit competitor comparison
