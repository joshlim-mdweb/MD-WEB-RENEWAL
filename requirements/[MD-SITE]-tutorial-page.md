## 1. 개요

Marvelous Designer 튜토리얼 콘텐츠를 웹사이트에서 제공하는 페이지 그룹.  
콘텐츠는 **Zendesk**에서 관리하며, Zendesk API를 통해 화면에 렌더링한다.

### 1.1 데이터 구조 (Zendesk 계층)

```
카테고리 (Category)  — 튜토리얼
└── 섹션 (Section)   — 퀵 스타트, 툴과 메뉴 등
    └── 게시물 (Article)
```

### 1.2 페이지 구성

| 페이지 | URL 예시 | 역할 |
|--------|----------|------|
| 튜토리얼 홈 | `/tutorials` | 전체 섹션 카드 그리드 + 학습 도우미 |
| 게시물 목록 | `/tutorials/quick-start` | 섹션 내 게시물 리스트 |
| 게시물 상세 | `/tutorials/quick-start/windows-and-modes` | 영상 + 본문 |

### 1.3 그리드 시스템

- 12컬럼 그리드
- 사이드바 3컬럼 : 콘텐츠 9컬럼
- 사이드바 폭은 New Feature 페이지와 통일

## 2. 튜토리얼 홈 (`/tutorials`)

### 2.1 화면 구성

| 영역 | 설명 |
|------|------|
| GNB | 공통 GNB |
| Hero | 페이지 타이틀 + 설명 문구 |
| 섹션 카드 그리드 | Zendesk 섹션 목록 카드 렌더링 |
| 학습 도우미 | 매뉴얼 · 챗봇 · 커넥트 커뮤니티 |
| 유튜브 채널 링크 | MD 공식 유튜브 채널 목록 |
| Footer | 공통 Footer |

### 2.2 섹션 카드 그리드

- Zendesk 섹션 목록을 카드로 렌더링한다
- 카드 구성: 썸네일 이미지 + 섹션명 + 설명
- 썸네일: 섹션별 공통 이미지 별도 제작
  - Zendesk 섹션에 이미지를 직접 삽입하기 어려운 기술 제약 → **섹션 ID 매핑 방식**으로 이미지 구현
- 카드 클릭 시: 해당 섹션의 게시물 목록 페이지로 이동

**섹션 목록 (현행 기준):**

| 순서 | 섹션명 |
|------|--------|
| 1 | 퀵 스타트 |
| 2 | 툴과 메뉴 |
| 3 | 기본 의상 |
| 4 | 심화 의상 |
| 5 | 인테리어 원단 |
| 6 | 배경, 소품 |
| 7 | UEFN 크리에이터 튜토리얼 |
| 8 | 메타휴먼 및 언리얼 엔진 |

### 2.3 학습 도우미

| 항목 | 동작 |
|------|------|
| 매뉴얼 | 매뉴얼 페이지 내부 이동 |
| 마블러스 디자이너 챗봇 ↗ | 외부 링크, 새 탭 |
| 커넥트 커뮤니티 ↗ | 외부 링크, 새 탭 |

### 2.4 유튜브 채널 링크

- MD 공식 유튜브 채널 목록을 아이콘 + 채널명으로 표시

## 3. 게시물 목록 (`/tutorials/:section-slug`)

### 3.1 화면 구성

| 영역 | 설명 |
|------|------|
| GNB | 공통 GNB |
| Breadcrumb | 튜토리얼 > [섹션명] |
| 좌측 사이드바 | 전체 섹션 리스트 네비게이션 (3컬럼) |
| 게시물 리스트 | 현재 섹션의 게시물 목록 (9컬럼) |
| 챗봇 CTA | 챗봇과 함께 학습하기 ↗ |
| Footer | 공통 Footer |

### 3.2 좌측 사이드바

- 전체 섹션 목록을 단순 리스트로 표시
- 현재 진입한 섹션을 강조(active) 표시
- 섹션 클릭 시: 해당 섹션 게시물 목록 페이지로 이동

### 3.3 게시물 리스트

- 현재 섹션 헤딩 표시
- 게시물 항목: 순서 번호 + 제목 + 우측 chevron (>)
- 게시물 간 구분선
- 클릭 시: 해당 게시물 상세 페이지로 이동

### 3.4 챗봇 CTA

- "챗봇과 함께 학습하기 ↗" 버튼
- 외부 링크, 새 탭
- 본문 우측 상단 배치

## 4. 게시물 상세 (`/tutorials/:section-slug/:article-slug`)

### 4.1 화면 구성

2단 레이아웃 (3:9 그리드).

| 영역 | 설명 |
|------|------|
| GNB | 공통 GNB |
| Breadcrumb | 튜토리얼 > [섹션명] > [게시물명] |
| 좌측 사이드바 | 게시물 목록 페이지와 동일한 섹션 리스트 (3컬럼) |
| 본문 영역 | 영상 + 게시물 내용 (9컬럼) |
| Footer | 공통 Footer |

### 4.2 본문 영역 — 상→하 순서

| 순서 | 영역 | 설명 |
|------|------|------|
| 1 | 영상 플레이어 | 유튜브 iframe 임베드, 최상단 배치 |
| 2 | 게시물 메타 | 업데이트 날짜, 버전 안내 문구 |
| 3 | 게시물 본문 | Zendesk 게시물 텍스트 콘텐츠 |
| 4 | Share 버튼 | 링크 복사 + Facebook + X + LinkedIn |
| 5 | 이전/다음 게시물 | 같은 섹션 내 순서 기반 네비게이션 |
| 6 | 관련 문서 | Zendesk Related articles API |
| 7 | 챗봇 CTA | 챗봇과 함께 학습하기 ↗ |

### 4.3 영상 플레이어

- 유튜브 영상을 iframe으로 임베드
- 페이지 최상단 배치
- 자동재생 없음 (iframe 환경 기술 제약)

### 4.4 게시물 메타

- 업데이트 날짜 (예: Updated Apr 17, 2026)
- 버전 안내 문구 (예: 이 비디오는 2024.2 버전까지의 메뉴 옵션 정보를 포함하고 있습니다)

### 4.5 Share 버튼

- 구성: 링크 복사 / Facebook / X / LinkedIn
- 링크 복사: 현재 페이지 URL 클립보드 복사

### 4.6 이전/다음 게시물 네비게이션

- 같은 섹션 내 순서 기반
- 첫 번째 게시물: 이전 없음
- 마지막 게시물: 다음 없음

### 4.7 관련 문서

- Zendesk Related articles API 렌더링
- 형식: 제목 리스트 + 링크
- 본문 하단 배치 (우측 사이드바 아님)

### 4.8 챗봇 CTA

- "챗봇과 함께 학습하기 ↗"
- 관련 문서 하단 배치
- 외부 링크, 새 탭

## 5. 공통 사항

### 5.1 다국어 처리

- 기본 언어: 영어

### 5.2 제외 항목 (확정)

| 항목 | 제외 사유 |
|------|-----------|
| 자동재생 | iframe 환경 기술 제약 |
| 최근 본 콘텐츠 | Zendesk API 미지원 + 필요성 낮음 |
| 검색 기능 | 튜토리얼 텍스트 부족으로 검색 결과 없음 빈번 |
| 사이드바 아코디언 | 제외, 단순 리스트로 구성 |
| 3단 레이아웃 | 콘텐츠 영역 협소 |
| 매뉴얼/FAQ | 별도 스코프, 이번 명세 제외 |
